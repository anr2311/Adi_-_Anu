ADITYA & ANUSHREE — TRADITIONAL SOUTH INDIAN WEDDING INVITATION

A responsive, fully static wedding invitation. No bundler or build step needed.

PREVIEW LOCALLY
Open index.html in your browser, or use VS Code Live Server.

PUBLISH ON NETLIFY
Connect the GitHub repository to Netlify (publish directory: repository root),
or download this branch as a ZIP and drag the extracted folder onto Netlify Drop.

FILES
- index.html: invitation content and semantic page structure
- style.css: palette, ornaments, temple architecture, typography and responsive layout
- script.js: Muhurtha countdown (India Standard Time)
- assets/: the original, UNMODIFIED couple photographs and rings; temple-pillar.svg; new favicon.svg

NOTES
- Real couple photographs and rings photo were preserved without edits or AI modifications.
- Unused photo assets remain in the repository, but there is no gallery section.
- The site's venue section uses a clickable directions link rather than a QR.
- Event calendar links use a suggested two-hour-and-a-half reception duration and
  one-hour Muhurtha duration for calendar placeholders only; only the START times are
  confirmed, so verify these calendar end times if you rely on them.

- The live site is not published by this branch; merge the PR and deploy when ready.
