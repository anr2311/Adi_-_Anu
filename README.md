# Aditya & Anushree — Royal South Indian Wedding Invitation

**Branch:** design/royal-south-indian-reference

This is a **fresh implementation** inspired by the *visual direction* of the public Priya & Arjun wedding-card project: ceremonial grandeur, ruby/gold/ivory palettes, and layered South Indian wedding artwork.

**Reference:** https://github.com/crazyaswin/wedding-card

The reference repository does **not include an explicit license**. No source code, photographs, temple renders, or other reference assets were copied. The new HTML, CSS, JavaScript and decorative floral toran are original to this branch.

## Preview

Open \`index.html\` with VS Code Live Server, or deploy this branch to a Netlify preview. No build tools required.

## Artwork layers

- \`assets/left_crop.png\` / \`assets/right_crop.png\`: existing real pillar artwork, feathered at the edges; **not approximated as CSS pillars**.
- \`assets/toran-original.svg\`: newly drawn original floral garland and hanging bell ornament.
- \`assets/couple-portrait-hero.jpg\`: uses the unmodified uploaded couple photograph.
- \`assets/rings.jpg\`: existing rings image with background feathering.
- Other couple and venue assets remain in the branch for future improvements.
